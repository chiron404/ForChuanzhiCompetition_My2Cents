# 安装运行与故障排查

对应 PDF 第 2 页

## 准备环境

准备 Node.js 20.19+，优先匹配已有验证环境 Node.js 24.15.0，并准备 pnpm 11.25.0。获取完整工程与 pnpm-lock.yaml 后，在工程根目录打开终端。首次安装需要网络；安装环境尚未在第二台干净机器验证。

```text
node --version
pnpm --version
pnpm install --frozen-lockfile
# 仅在 .env.local 不存在时执行
Copy-Item .env.example .env.local
npm run dev
```

浏览器访问 http://127.0.0.1:3000/。关闭终端或停止服务后，本地地址将不可访问。127.0.0.1 仅指访问者自己的电脑，不能作为发给评委的公网体验地址。

## 生产运行与校验命令

```text
npm run typecheck
npm test
npm run evaluate
npm run build
npm start
```

| 现象 | 排查方式 |
| --- | --- |
| 无法访问本地地址 | 检查终端服务是否启动、实际端口和错误信息；不要只双击源码文件 |
| 依赖安装超时 | 检查网络并重试原锁文件安装，不随意重建依赖版本 |
| PDF worker 缺失 | 确认 postinstall 已执行；必要时运行 npm run postinstall |
| 真实模式无结果 | 检查服务端配置、模型可用性、网络与配额；不要将占位数据当分析结果 |
| 浏览器存储受限 | 改用允许本机存储的环境，或先导出 JSON 保存当前会话 |

> 已有验收结果是历史证据，以上命令是复现步骤，不表示本次报告制作重新执行并全部通过。

# 环境变量与依赖说明

对应 PDF 第 3 页

```text
LLM_API_KEY=
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_CONFIG_VERSION=1
```

保持密钥为空即可使用演示模式。真实模式在服务端 .env.local 中填写自己的有效密钥与模型配置，重启服务生效。不得用 NEXT_PUBLIC_ 暴露密钥，不应将实际 .env.local 上传公开仓库。

## 缓存与数据

配置或提示词变化后递增 LLM_CONFIG_VERSION，避免复用旧模型配置下的本机缓存。文件在浏览器解析；真实调用会发送必要文本、抽取结果与人工答复。Markdown 导出便于阅读，JSON 导出可用于重新导入恢复。

# 评审体验路线与结果核对

对应 PDF 第 4 页

| 步骤 | 操作 | 应观察的结果 |
| --- | --- | --- |
| 1 | 首页点击“试试示例文档” | 固定示例：12 条需求、9 个缺口、18 项标准任务 |
| 2 | 缺口审查点击两处访问范围引用 | 左侧定位“仅本校”与“外校下单”的原文 |
| 3 | 采纳图片数量、大小和格式答复 | 答复记录可见；未回答的阻塞项继续提示 |
| 4 | 任务蓝图点击重新拆解并展开图片任务 | 描述与验收标准纳入确认后的图片限制 |
| 5 | 切换概览、标准、详细 | 固定样例对应 9、18、36 项；依赖图更新 |
| 6 | 标准档移除 T-03 图片任务 | 任务 18 变 17；R-02 未覆盖，覆盖率约 92% |
| 7 | 在红格补充任务与验收标准 | 提交后覆盖率恢复 100% |
| 8 | 决策档案搜索信用并加载冲突示例 | 并列展示历史与补充决定，双方原文可查 |
| 9 | 评测台运行演示管线自检 | 指标、失败案例、匹配口径及局限可见 |
| 10 | 导出 Markdown / JSON | 下载相应文件；JSON 可通过验证后重新导入 |

若已有缓存或人工修改，结果可能与初始计数不同。准备演示时可以使用重新分析恢复示例；不要为追求固定数字把真实错误隐去。评测台返回结果页可能呈现初始样例，导出前应核对当前结果是否是所需版本。

> 三个必讲边界：固定样例不是模型真实准确率；100% 覆盖仅针对已抽取需求；建议工时和置信度不是确定承诺。

已有录屏时长约 5 分 4 秒，分辨率 2558×1438、30 fps。本材料包不包含视频，也未制作配音成片。视频应另行补充普通话讲解并检查最终时长与清晰度。
